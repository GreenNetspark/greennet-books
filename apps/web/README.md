# GreenNet Books - Web Application

> Next.js App Router front end for **GreenNet Books** (GreenNetSpark).

Refer to the main [README](../../README.md) for full project architecture, starter task details, and documentation.

## Running Locally

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) (auto-redirects to `/customers`).
